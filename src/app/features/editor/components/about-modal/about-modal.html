About the Project

MarkdownView is an open-source, privacy-first markdown editor built for developers, researchers, and creators. It brings together the speed and fluidity of Notion with the uncompromised flexibility of raw Markdown, scientific $\LaTeX$ KaTeX math, dynamic Mermaid diagrams, and native local filesystem synchronization.

Core Architecture & Power

Notion-Style Slash Commands

Summon headings, code blocks, task lists, and diagrams with a single / keystroke.

KaTeX Scientific Math

Full inline and block mathematical formulas rendered at 60 FPS.

Mermaid.js Visual Diagrams

Render flowcharts, sequence diagrams, mindmaps, and architecture diagrams effortlessly.

Local File System Sync

Bi-directional saving directly to your computer's folders via Web File System Access API.
