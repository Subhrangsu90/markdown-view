Notion Slash Commands

Type / on any line to open quick-insert menu:

/h1, /h2, /h3 Heading blocks
/todo Interactive task item with checkbox
/code Syntax highlighted code block
/table Pre-structured Markdown table
/math KaTeX LaTeX equation block
/mermaid Mermaid flowcharts & sequence diagrams
/callout Notion-style highlight callouts

Markdown Syntax

**bold** Bold text
*italic* Italic text
~~strike~~ Strikethrough
`code` Inline monospace code
> quote Blockquote citation
- [ ] task Task list item
> [!NOTE] Alerts: NOTE, TIP, IMPORTANT, WARNING, CAUTION
