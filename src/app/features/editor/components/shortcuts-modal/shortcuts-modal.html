Notion Slash Commands & Dynamic Blocks

Type / on any line to open quick-insert menu:

/ai summarize Summarize active document or selection
/ai proofread Fix grammar, typos & enhance style
/ai generate-mermaid Generate Mermaid diagrams from text
/ai Open On-Device / Cloud AI Assistant
/h1, /h2, /h3 Heading blocks
/todo Interactive task item with checkbox
/code PrismJS syntax-colored code block
/table Pre-structured Markdown table
/math KaTeX LaTeX equation block
/mermaid Mermaid flowcharts & sequence diagrams
/callout Alert callouts (> [!NOTE], TIP, IMPORTANT, WARNING, CAUTION)
